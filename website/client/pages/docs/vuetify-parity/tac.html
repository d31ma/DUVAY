Vuetify parity

DuVay's automated inventory is pinned to Vuetify 4.1.7. It pairs every published Vuetify component with a Light-DOM w-* element and compares every HTML-addressable prop with the attributes the element actually observes or reads.

Current result

  • 206 / 206 Vuetify component names have DuVay counterparts.
  • 0 applicable attribute gaps remain.
  • 257 DuVay custom elements are registered, including lower-level and DuVay-specific elements beyond Vuetify's public inventory.

What “applicable” means

DuVay is framework-independent, uses native DOM events, and has no Vue renderer or Vue Router. Props that only carry Vue components, router records, callback functions, or opaque objects cannot be represented faithfully as HTML attributes. They are audited explicitly rather than silently counted as supported. Use the component's documented native attribute, JavaScript property, method, slot, or event instead.

Vue rendering and internal state

tag, symbol, defaults-target, eager, focused, model-modifiers, and component-specific model-value occurrences that have no distinct native state. DuVay uses semantic native roots, immediate Light-DOM rendering, :focus/:focus-visible, and the documented value, open, active, or model-value contract for each component.

Vue Router

to, replace, and exact. Link-capable DuVay components use native href, target, and rel; application routers can intercept the resulting click event.

Callback and object configuration

rules, value-comparator, custom-filter, custom-key-filter, custom-key-sort, get-matches, counter-value, weekday-format, month-format, year-format, day-format, header-format, title-format, item-selectable, item-children, item-title, item-value, item-type, item-props, sort-func, filter, load-children, group-key, options, list-props, menu-props, header-props, row-props, and cell-props. Components that expose a safe vanilla property form document it on their own API page; string and JSON attribute equivalents remain attributes.

Vue overlay strategies

attach, activator, activator-props, content-props, location-strategy, scroll-strategy, and transition-duration. DuVay uses authored activator slots, native DOM targets, containment attributes, CSS transitions, and browser scrolling.

Inherited or internal-only occurrences

overlaps is internal layout state. Calendar callback props interval-format, interval-style, and show-interval-label use DuVay's documented vanilla properties and CSS hooks. Vuetify's inherited type and hide-spin-buttons text-field props do not apply to the non-numeric select control.
