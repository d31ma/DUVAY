Installation

DuVay has zero dependencies and no build step. Paste a hosted URL into your HTML and go.

No package manager

DuVay is not published to npm or any other package registry. It ships as hosted files on GitHub Pages. Link them directly, or vendor them into your own asset pipeline.

Import the full stylesheet from CSS:

@import "https://d31ma.github.io/DUVAY/latest/duvay.css";

When using web components, import the module from your JavaScript entrypoint:

import "https://d31ma.github.io/DUVAY/latest/duvay-wc.js";

Latest release

These GitHub Pages URLs always serve the newest CalVer build.

<link rel="stylesheet" href="https://d31ma.github.io/DUVAY/latest/duvay.min.css">
<script src="https://d31ma.github.io/DUVAY/latest/duvay.min.js" defer></script>

Pin to a version

Replace VERSION with any CalVer release you want to lock to (for example 26.24.12). Versioned URLs never change.

<link rel="stylesheet" href="https://d31ma.github.io/DUVAY/versions/VERSION/duvay.min.css">
<script src="https://d31ma.github.io/DUVAY/versions/VERSION/duvay.min.js" defer></script>

Web Components

To use the DuVay web component library, import the module after the stylesheet:

<link rel="stylesheet" href="https://d31ma.github.io/DUVAY/latest/duvay.min.css">
<script type="module" src="https://d31ma.github.io/DUVAY/latest/duvay-wc.min.js"></script>

<w-btn variant="filled">Click me</w-btn>

Selective CSS

For app bundles, import only the component CSS you use. Each component stylesheet imports the DuVay core layer.

@import "https://d31ma.github.io/DUVAY/latest/components/buttons.css";
@import "https://d31ma.github.io/DUVAY/latest/components/cards.css";
@import "https://d31ma.github.io/DUVAY/latest/components/dialogs.css";

If you prefer an explicit dependency chain, import core once and then component files.

@import "https://d31ma.github.io/DUVAY/latest/core.css";
@import "https://d31ma.github.io/DUVAY/latest/components/buttons.css";
@import "https://d31ma.github.io/DUVAY/latest/components/cards.css";
