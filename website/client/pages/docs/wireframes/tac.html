Wireframes

Ready-made layout scaffolds to start a new application. Copy a wireframe, replace the placeholder content, and every region is already wired for responsive behavior and theming.

Blank

The minimal DuVay document: stylesheet, optional behavior layer, and a main region.

<!doctype html>
  <html lang="en" w-theme="auto">
  <head>
    <link rel="stylesheet" href="https://d31ma.github.io/DUVAY/latest/duvay.min.css">
    <script src="https://d31ma.github.io/DUVAY/latest/duvay.min.js" defer></script>
  </head>
  <body>
    <main class="w-main">
      <div class="w-container">Hello DuVay</div>
    </main>
  </body>
  </html>

App bar

A sticky top bar above a scrolling content area.

<w-app-bar sticky>
    <w-app-bar-title>Application</w-app-bar-title>
  </w-app-bar>

  <main class="w-main">
    <w-container>Content</w-container>
  </main>

Side navigation

An app bar plus a navigation drawer. The drawer collapses behind the nav icon on small screens.

<w-app-bar sticky>
    <w-app-bar-nav-icon aria-label="Open navigation"></w-app-bar-nav-icon>
    <w-app-bar-title>Application</w-app-bar-title>
  </w-app-bar>

  <w-navigation-drawer>
    <w-list>
      <w-list-item href="/">Home</w-list-item>
      <w-list-item href="/settings">Settings</w-list-item>
    </w-list>
  </w-navigation-drawer>

  <main class="w-main">
    <w-container>Content</w-container>
  </main>

Baseline

The full application shell: app bar, navigation drawer, content, and footer.

<w-app-bar sticky>
    <w-app-bar-nav-icon aria-label="Open navigation"></w-app-bar-nav-icon>
    <w-app-bar-title>Application</w-app-bar-title>
  </w-app-bar>

  <w-navigation-drawer>
    <w-list>
      <w-list-item href="/">Home</w-list-item>
    </w-list>
  </w-navigation-drawer>

  <main class="w-main">
    <w-container>Content</w-container>
  </main>

  <w-footer>Footer</w-footer>

Every wireframe also works without JavaScript when authored with the CSS-class equivalents (.w-app-bar, .w-navigation-drawer, .w-footer); the web-component tags simply generate the same markup. See Application layout for the full set of layout regions.
