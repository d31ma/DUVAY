Sync status

w-sync-status tells the user whether the app is online and how fresh the copy of the data on this device is, for example “Offline · updated 08:12 · 3 waiting to send”. It is one of the offline states pieces (docs/offline-states.md). Set state to online, syncing, offline or locked, and give it updated-at, pending and attention. Every state shows an icon and words, never colour alone.

States

When the state is online and nothing waits, the bar is hidden. Add show-online to keep it visible with “Up to date”.

Accessibility

  • The visible text is not a live region, so changes to the time and the counts are never announced.
  • The element owns one hidden role="status" line. It speaks, politely, only when state changes: the offline text, the locked text, or “Back online” when the state leaves offline or locked. syncing is not announced.
  • Changes within 2 seconds make one announcement, or none if the state ends where it started. Nothing is announced on first display.
  • The element never takes focus. Buttons in actions keep their normal tab order.
  • With reduced motion, a still icon replaces the spinner. The layout mirrors for right-to-left languages.
  • Use one w-sync-status per page for a state: two elements would announce the same change twice.
