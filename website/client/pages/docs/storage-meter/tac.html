Storage meter

w-storage-meter shows how much space an app’s offline copy uses on the device. Give it value and max in bytes; it shows a label, a bar in the linear progress style, and “312 MB of 1 GB used”. From warn-at (default 0.8) it says “Almost full” with an icon and the warning colour; from full-at (default 0.95) it says “Full” with the error colour. The words are always shown, so the state never depends on colour alone. It is part of the offline states.

Use the OS tabs above each example to compare the skins: iOS and macOS show “X of Y used” beside the label over a taller bar, as their Settings storage rows do; Android shows it under the label over a thin bar; Windows draws a thin bar on a 1px rail, like a WinUI ProgressBar; Linux keeps the pill trough of a GTK LevelBar.

One meter per domain

When the copy has several parts, show one meter per row, each with its own label and budget. A single bar split into coloured parts is not offered: it would need colour to tell the parts apart.

Accessibility

  • The rendered element has role="meter" with aria-valuemin, aria-valuemax, aria-valuenow (in bytes, never above max) and aria-valuetext, for example “850 MB of 1 GB used, Almost full”. Its name is the visible label.
  • It is not a live region and takes no focus. Changes are read when the user reaches the meter.
  • “Almost full” and “Full” are shown in words with an icon. The bar keeps 3:1 against its track, and the text 4.5:1, in the light, dark and high-contrast themes on every skin.
