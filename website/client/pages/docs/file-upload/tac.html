File upload

w-file-upload is a drag-and-drop upload area inspired by Vuetify's v-file-upload. It supports title, subtitle, browse-text, multiple, accept, show-size, clearable, and density.

Validation value

Add required to validate the selected files. When another component owns the real FileList, pass a serializable validation-value; empty arrays, null, false, and an empty string are treated as empty.
