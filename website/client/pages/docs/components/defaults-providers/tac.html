Defaults Providers

w-defaults-provider applies default attributes to descendant components, the attribute-driven analogue of Vuetify's VDefaultsProvider. Pass a defaults JSON object mapping a tag selector to the attributes it should receive. Defaults only fill in attributes a consumer hasn't set, and the nearest provider wins for nested scopes.

Provider-chain controls

Use scoped when a nested provider must not inherit omitted keys. Use reset="n" to skip the current provider and n enabled ancestor scopes, or root to resolve defaults from the outermost scope.

API

  • defaults — JSON mapping component selectors to default attributes.
  • disabled — bypass this provider.
  • scoped — block inheritance of omitted defaults from parent providers.
  • reset — skip this scope and the requested number of enabled ancestors; a bare attribute resolves from the outermost scope.
  • root — resolve descendants from the outermost provider.

Explicit values win

An attribute set directly on a component overrides the provider default; missing ones are still filled.

Nesting

Defaults merge across nesting: a nested provider overrides the keys it sets (here color) while keys it omits (variant) still inherit from the outer provider.
