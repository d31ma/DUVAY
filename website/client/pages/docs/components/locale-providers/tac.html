Locale Providers

w-locale-provider scopes language and text direction around a section of content, matching Vuetify's VLocaleProvider. Descendants inherit lang and dir, so logical CSS properties and :dir() flip automatically for right-to-left languages.

Locale

Set locale to a BCP-47 language tag; it is applied as lang on the scope.

Messages

Pass locale-keyed JSON to messages. Descendant code can call the closest provider's translate(path, replacements) method; missing entries fall back through fallback-locale and then return the requested key.

Enregistrer

API

  • locale — BCP-47 language tag applied to the scope.
  • fallback-locale — locale used when the active dictionary lacks a key.
  • rtl — set right-to-left text direction.
  • messages — direct or locale-keyed JSON translation dictionary.
  • translate(path, replacements) — resolve a dotted key and replace tokens such as \{name\}.

Right-to-left

Add rtl to flip direction for languages such as Arabic or Hebrew. Layout that uses logical properties mirrors automatically.
